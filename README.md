# queue-music-player

A shared playlist for a room of friends. One device — the **Player** — is paired
to the speaker and is the only thing that makes sound. Everyone else opens the
site on their phone as a **Controller**: they add, remove and reorder tracks, and
can skip or pause, but no audio ever plays on their own device.

> **Status: in design.** Nothing is implemented yet. See [CONTEXT.md](./CONTEXT.md)
> for the domain language the design is being built on.
